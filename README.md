# CSST106 – Computer Vision Activities

## Description

This repository contains a collection of laboratory activities and experiments completed for the CSST106 – Computer Vision course. These activities explore fundamental concepts and techniques in computer vision, including image processing, edge detection, histogram analysis, feature detection, dimensionality reduction, and image segmentation.

The activities utilize Python and Jupyter Notebook to demonstrate the practical application of computer vision algorithms and techniques in analyzing, processing, and interpreting digital images.

## Laboratory Activities

- **Lab 1 – Image Processing:** Explores the fundamental concepts of digital images and basic image manipulation techniques.
- **Lab 2 – Edge Detection:** Identifies edges, boundaries, and significant structures within digital images.
- **Lab 3 – Histogram Analysis:** Examines pixel intensity distributions and image characteristics.
- **Lab 4 – SURF Feature Detection:** Explores feature detection and extraction using Speeded-Up Robust Features (SURF).
- **Lab 5 – PCA in Computer Vision:** Demonstrates Principal Component Analysis for dimensionality reduction and feature representation.
- **Lab 7 – Image Segmentation:** Explores techniques for dividing images into meaningful regions.

## Summary

These laboratory activities demonstrate the practical applications of computer vision through hands-on experimentation and programming. They provide a foundation for understanding how computers process, analyze, and interpret visual information while developing technical and problem-solving skills in digital image processing.
